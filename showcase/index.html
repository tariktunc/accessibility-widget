Neden "Overlay" (Kaplama) Değil?

Piyasada "yapay zeka ile sitenizi tek tıkla %100 ADA uyumlu yapıyoruz" iddiasıyla satılan ticari kaplamalar (accessiBe vb.) 2025'te FTC cezalarına çarptırılmış ve engelli hakları savunucuları tarafından kınanmıştır.

Özellik / Yaklaşım Sahte Kaplamalar (Overlays) Blakfy Accessibility Widget
DOM Müdahalesi (Runtime Rewrite) Sayfa kodunu runtime'da değiştirir, ekran okuyucuları bozar. Sıfır DOM müdahalesi. Yalnızca CSS sınıfları ve değişkenleri yönetir.
Yapay Zeka Alt-Text Uydurması Fotoğraflara bağlamsız, hatalı otomatik açıklamalar yazar. Uydurma yapmaz. Gerçek erişilebilirliğin site sahibinin işi olduğunu açıkça belirtir.
Kullanıcı Takibi ve Parmak İzi (Fingerprinting) Engelli bireylerin yardımcı teknolojilerini izler ve fişler. Sıfır telemetri. Tercihler yalnızca kullanıcının kendi tarayıcısında saklanır.
Yasal Koruma & Beyan Yanıltıcı "Dava edilemezsiniz" iddiaları (FTC 2025 cezası). Dürüst yaklaşım: Ek bir kullanıcı tercih katmanı sunar; EAA 2025 ve WCAG 2.2 AA UI uyumludur.
Paket Boyutu & Performans Yüzlerce kilobayt, ağır harici kütüphaneler. Yalnızca 18 KB (Gzip). Preact ve Shadow DOM ile milisaniyeler içinde açılır.

Hızlı Kurulum Yöntemleri

İster tek satır CDN scripti ile ister Next.js ve React paketleriyle projenize dahil edin.

1. CDN İle Entegrasyon (Tüm Siteler) Vanilla HTML / WordPress 
<!-- HTML kapanış </body> etiketinden hemen önce ekleyin -->
<script
  src="https://cdn.jsdelivr.net/npm/@blakfy/accessibility-widget@v2/dist/widget.js"
  data-locale="tr"
  data-theme="auto"
  data-position="bottom-left"
  defer
></script>
2. Next.js App Router (app/layout.tsx) Next.js 14 / 15 
import Script from 'next/script';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="tr">
      <body>
        {children}
        <Script
          src="https://cdn.jsdelivr.net/npm/@blakfy/accessibility-widget@v2/dist/widget.js"
          strategy="lazyOnload"
          data-locale="tr"
          data-position="bottom-left"
        />
      </body>
    </html>
  );
}
3. NPM Paketi ile Kurulum NPM / PNPM 
npm install @blakfy/accessibility-widget
